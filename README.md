# Fullstack application for learning
Designed as a headless RESTful API connected with a frontend layer.
User is able to create collections of 'flashcards' and revise them to train their memory.

**Technologies used in the project:**
  - *ASP.NET Core* with *C#*
  - *EntityFramework* with *MSSQL*
  - *JWT Tokens*

  - *React* with *Typescript* and *Vite*
  - *Tailwind CSS*
